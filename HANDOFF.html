1. Primary Goal

ROS 2 Jazzy package hound_core that brings up a Intel RealSense D455 (by hardware serial), NVIDIA Isaac ROS Visual SLAM (cuVSLAM), optional ArduPilot MAVROS, and a semantic segmentation pipeline for navigation / dynamic obstacle handling.

Architecture follows the bimanual package pattern: all tunables live in config/SSoT.yaml; launch/robot.launch.py reads it at launch time (no rebuild needed for config edits when using symlink install).

2.2 Segmentation pipeline (final architecture)

Color image (/camera/color/image_raw)
        │
        ▼
┌───────────────────────┐
│  clipseg_mask_node    │  CIDAS/clipseg-rd16, torch.compile
│  (coarse, ~10 Hz)     │  Grouped prompts → argmax label map
└───────────┬───────────┘
            │ publishes:
            │   /segmentation/labels      (mono8: 0=none, 1=traversable, 2=non_traversable, 3=people)
            │   /segmentation/boxes       (Float32MultiArray: class_idx + bbox for SAM)
            │   /segmentation/overlay     (optional debug, viz_overlay=false by default)
            ▼
┌───────────────────────┐
│  sam_refine_node      │  EfficientViT-SAM-L0, torch.compile encoder
│  (refined, ~10 Hz)    │  Subscribes: color + boxes (matched by stamp)
└───────────┬───────────┘
            │ publishes:
            │   /segmentation/refined_traversability  (rgb8: G=traversable, R=non-traversable, B=none)
            │   /segmentation/refined_people_mask     (mono8: people/dynamic)
            │   /segmentation/refined_overlay         (optional debug, sam_overlay=false)
Design decisions locked in:
  • CLIPSeg produces coarse mono8 label map + box prompts only (no in-process SAM).
  • SAM runs in a separate parallel process to decouple latency.
  • SAM output is RGB traversability + separate people mask (not mono8 labels).
  • Experimental features removed: tiling, MaskCLIP head, DINO.txt, guided filter, in-process SAM.
  • torch.compile(mode="reduce-overhead") for both CLIPSeg and SAM (not max-autotune — Orin NX has too few SMs).
  • Prompts grouped by navigation category; aggregate: max within groups; sky suppressed via suppress_prompts.

7. Critical Issues & Fixes Applied

7.1 cuVSLAM SIGILL (SVE2 mismatch)

Problem: Apt libcuvslam.so contained SVE2 instructions incompatible with Orin ARMv8.2 → SIGILL on load.

Fix: Rebuilt libcuvslam.so from cuVSLAM v15.0.0 source natively on Orin with -march=native. VSLAM now runs (confirmed: cuVSLAM 15.0.0, Multicamera mode).

7.2 D455 IMU unavailable

Problem: Kernel 6.8.12-tegra lacks hid-sensor-accel-3d / hid-sensor-gyro-3d modules. Librealsense reports "No HID info provided, IMU is disabled."

Fix: Not software-fixable. Keep enable_imu: false, tracking_mode: 0 (stereo-only). VIO would need kernel module build from tegra source.

7.3 MAVROS build failures

Problem: Stale MAVROS source in workspace; GeographicLib 1.x vs 2.x; tf2_eigen.h vs .hpp on Jazzy.

Fix: Install Jazzy MAVROS via apt; COLCON_IGNORE the source tree. Custom GCS throttle patch was implemented for separate USB vs WiFi stream rates.

7.4 torch.compile on Orin NX

  • Use mode="reduce-overhead", dynamic=False for CLIPSeg and SAM encoder.
  • max-autotune warns "Not enough SMs" — no benefit, longer startup.
  • SAM warmup: 10 iterations needed for CUDA graph capture to settle.

12. MAVROS GCS Rate Limiting (custom patch)

User needed different stream rates for USB (FCU) vs WiFi (GCS). A patch was implemented on MAVROS router: 

mavros_router:
  ros__parameters:
    gcs_block_stream_requests: false
    gcs_throttle_hz: 0.0
    # gcs_throttle_msgids: [30, 27, 33, 32, 65, 36, 74]

Configured via mavros.node_params in SSoT. Set gcs_throttle_hz to desired GCS cap (e.g. 4.0).

13. Label / Color Encoding

CLIPSeg coarse labels (mono8)

PALETTE in utils.py:
  label 1 (traversable)     → green  (0, 200, 0)
  label 2 (non_traversable) → red    (220, 0, 0)
  label 3 (people)          → blue   (0, 80, 255)
  label 0                   → black  (none/unknown)

SAM refined traversability (rgb8)

Channel R = non-traversable probability
Channel G = traversable probability
Channel B = none (neither traversable nor non-traversable)

Group → SAM output mapping

Derived in robot.launch.py from SSoT:

positive_groups: ["traversable"]   → green channel
negative_groups: ["non_traversable"] → red channel
everything else (e.g. people)      → separate people mask
